# ⚔️ Ravion - Distribuição Oficial do Launcher

Bem-vindo ao repositório oficial de distribuição e atualizações do **Ravion**.  
Este repositório é utilizado exclusivamente para a entrega contínua de atualizações e downloads dos binários do jogo.

---

## 📥 Como Baixar e Jogar

Para começar a jogar, você precisa apenas do inicializador do jogo (**Bootstrapper**):

1. Acesse a página de [**Releases Mais Recentes**](../../releases/latest).
2. Na seção **Assets**, baixe o pacote correspondente ao seu sistema operacional:
   - **Windows:** `Ravion.PreLauncher.exe`
   - **Linux:** `Ravion.PreLauncher`
3. Execute o inicializador:
   - Ele verificará a integridade dos arquivos e fará o download da versão mais atual do Launcher automaticamente.
   - Quando a barra de progresso for concluída, o jogo estará pronto para iniciar!

---
